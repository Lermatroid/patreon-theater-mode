# Patreon Theater Mode

A tiny no-build Chrome extension that adds a YouTube-style theater mode toggle to Patreon video posts.

## Load It In Chrome

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Click **Load unpacked**.
4. Select this folder: `/Users/liam/Documents/Projects/Personal/patreon-theater-mode`.
5. Reload the Patreon tab that is playing the video.

## Use It

- Click the floating **Theater** button while a Patreon video is visible.
- Press `T` to toggle theater mode.
- Press `Escape` to leave theater mode.

The extension detects the largest visible Patreon video or embedded video frame and promotes its player area to the top of the page, leaving the post content scrollable below it.
